# 防災 GIS 資料開箱與應用

Denny Huang｜開放圖資、防災應用與資料判讀

- [投影片](https://denny.one/20261002-gis/)
- [Demo 教材](https://github.com/denny0223/ntpc-multiformat-demo-kit)

## 編輯與建置

`slide.md` 為投影片正文，`theme/civic-atlas.css` 為主題，圖片放在 `img/`。

```sh
npm install
npm run build
```

建置產生 `index.html`；編輯時可用 `npm run watch`。GitHub Pages 從 `gh-pages` 根目錄發佈。
